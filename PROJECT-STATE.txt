What the site is
----------------
A Jekyll site for GitHub Pages, written for readers who are not Christians.
Live address (from _config.yml): https://forestwalkuk.github.io/truthpeaceandlove
Menu: #home #gospels #creation #deeper #mystory #blog. Footer: #notes #howitiswritten.
Doors (home page): #neverthought #weary #isittrue #otherbeliefs #shutout #readjesus.

How to publish a new version
----------------------------
1. Pull origin in GitHub Desktop first.
2. Unzip the archive and copy its contents over the repository (keep the .git folder).
   Copy over; do not replace the folder.
3. Before committing, look down the list in GitHub Desktop. Anything shown as DELETED
   (red) that you did not mean to delete, especially in _posts, untick it.
4. Commit and push. Check the footer shows the new version number.

The design (v2.0)
-----------------
- Typography only, no pictures. Hashtags and headings: Inter Black Italic (and Extra Bold
  Italic for the menu), self-hosted. Reading text: Source Serif 4, self-hosted.
- Colours: dark by default (white on black). Masthead button cycles #dark, #light,
  #soft (muted light); the reader's choice is remembered on their device. The colour of every # is set by --hash
  at the top of style.css (black now; var(--rubric) would make them red).
- Red is reserved for Scripture (and the menu marker). LORD and KJV are set in small
  capitals automatically.
- Three fading verses on the home page: John 14:6, Romans 5:1, 1 John 4:9.
- VerseClick pop-ups for Authorised Version references (off on the Geneva Gospel pages).

How to add things
-----------------
A new page in a section (e.g. Creation):
  Make creation/my-page.md beginning:
    ---
    layout: article
    title: My Page
    tag: mypage
    deck: One plain sentence shown under the hashtag.
    section: creation
    order: 4
    permalink: /creation/my-page/
    ---
  Write the text below. "## words" makes a #words sub-heading. The section's front page
  lists it automatically, in "order".
A new section:
  Make a folder with index.md (layout: section, title, tag, deck, permalink /name/),
  then add the section to the menu in _data/sections.yml (tag, name, url).
A blog post on a section page:
  Add to the post's front matter, e.g.  sections: [otherbeliefs, deeper]
A new door on the home page:
  It is already listed in _data/sections.yml; it appears as soon as a page exists at
  its url. To add or reword a door, edit that file.
A page that is not ready: put "published: false" in its front matter.
Blog posts: as before (_posts, front matter with title only). From v2.3 ZIPs DO carry _posts,
  copied from the live repository when the ZIP is built (the post was lost twice without it).
The AI note at the foot of each page:
  The wording is in _data/ai_notes.yml. Defaults are in _config.yml (standard; gospels for
  /gospels/; post for blog posts). A page can choose its own line, e.g.  ai_note: story,
  or have none:  ai_note: none.  Add a new line to ai_notes.yml for a page that needs
  different wording; keep every line true for every page that uses it.
The stylesheet link carries ?v=<site_version>, so raising the version number in _config.yml
makes browsers load the new styles straight away.
