Version 2.3 (25th October, A.D. 2026) - how this site is written
------------------------------------------------------------------
Feature: new page "How this site is written" (/how-this-site-is-written/, #howitiswritten):
  where AI is used on the site and where it is not, the Bible texts, the dots on blog posts,
  and why readers are told. In Carl's voice; DRAFT wording for Carl to check.
Feature: an AI note at the foot of every page, set in one place. The default layout shows a
  short line chosen by "ai_note:", followed by a link to the new page. Wording lives in
  _data/ai_notes.yml (standard, gospels, story, post); _config.yml gives the defaults
  (standard everywhere, gospels for /gospels/, post for blog posts); My Story uses "story".
  "ai_note: none" turns the line off (used on the new page itself).
Feature: #howitiswritten added to the footer beside #notes (_data/sections.yml).
Feature: /how-these-posts-are-written/ (the address named in the blog brief) sends readers on
  to the new page, so links made from the brief still work.
Fix: the Believing Prayer post was deleted from the repository again by the v2.2 commit
  (0c02ac3). Restored exactly as in v2.1 (0a3bde8). From now on ZIPs DO carry _posts, copied
  from the live repository at build time.
Files added: how-this-site-is-written.md, how-these-posts-are-written.html, _data/ai_notes.yml,
  _posts/2026-10-18-believing-prayer-catechism-mark-11-24.md.
Files changed: _config.yml, _data/sections.yml, _layouts/default.html, assets/css/style.css,
  my-story.md.

Version 2.2 (24th October, A.D. 2026)
-------------------------------------
Fix: on phones, the #soft colours looked the same as #dark. The phone was still using its
  saved copy of the v2.0 stylesheet, which has no soft colours (and, with the phone set to
  dark, showed anything other than "light" as dark). The stylesheet address now carries the
  version number (style.css?v=2.2), so every new version makes browsers fetch the new file.
Files changed: _config.yml, _layouts/default.html, assets/css/style.css (version line only).
Note: this ZIP has no _posts folder again (the restored post is safely in the repository).

Version 2.0 (24th October, A.D. 2026) - new typographic design
--------------------------------------------------------------
Feature: whole new look, typography only (no pictures). Bold black italic hashtags
  (Inter Black Italic) for the menu, page titles and doors; Source Serif 4 kept for all
  reading text. Black on white; dark mode is white on black. Red still only for Scripture
  (bar beside quotations, chapter and verse numbers) and the menu marker.
Feature: _data/sections.yml controls the menu, the home-page doors, the lines under the
  doors and the footer links. An entry only shows once its page exists (no dead links).
Feature: new layouts. page (hashtag title from "tag:", optional "deck:" line), section
  (a section's front page; lists its pages automatically), article (a page in a section;
  "## words" sub-headings show as #words; links back to its section), home (big title,
  fading verses, welcome, doors). Post layout restyled.
Feature: Creation section: creation/index.md (live) and creation/theflood.md (DRAFT,
  "published: false" until Carl has checked it).
Change: the three fading verses now appear on the home page only, under the title.
  The "verses:" front-matter switch is no longer used (harmless where it remains).
Change: menu is #home #gospels #creation #mystory #blog (#deeper appears once a
  /deeper/ page exists). Notes moved to the footer as #notes.
Change: Gospels introduction now includes "The word Gospel simply means good news."
  (Carl's decision of 16 October; the v1.3 ZIP lacked it.)
Removed: home-page pictures (assets/images/illustrations/) and their footer credit.
Fix: the hidden verse-1 number on chapter pages could show as a small superscript

Files added: _data/sections.yml, _includes/page-head.html, _includes/section-list.html,

Files changed: _config.yml, _layouts/default.html, _layouts/post.html,
  assets/css/style.css, index.md, my-story.md, notes.md, blog.md, gospels/index.md.

Version 1.0 (18th October, A.D. 2026)
--------------------------------------
Fix: Bold italic text (e.g. the italic "them" inside a bold Scripture quotation) no longer
  looks smeared. The site had no Semibold Italic font, so browsers faked one by thickening
  the regular italic. Added assets/fonts/SourceSerif4-SemiboldItalic.woff2 (Source Serif 4,
  same version 4.004, SIL Open Font Licence, Latin set from Fontsource, about 21 KB; it is
  downloaded only on pages that use bold italic) and its @font-face rule.
Improvement: font-synthesis:small-caps on html, so browsers never fake bold or italic
  again (small capitals are still allowed).
Fix (post, not in this ZIP): the Believing Prayer post had no front matter, so Jekyll made
  a title from the file name and the layout showed it above the post's own # heading.
  Front matter title added (in quote marks because of the colons) and the # line removed.
Files changed: _config.yml, assets/css/style.css. File added: the font above.
