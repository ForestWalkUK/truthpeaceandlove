{% comment %} Heartbeat line across the home-page title (v2.7; single pass since v2.8). A drawing only: hidden from screen readers, never catches a tap, not printed. It crosses the screen once when the page opens, then once more every few minutes while the reader stays on the page. Settings are on the canvas below: data-bpm beats per minute (70: an adult at rest) data-speed how fast the line is drawn, in screen pixels per second data-reach how far the peak rises above "Truth" and the trough falls below "Love", in cm data-every minutes from the start of one pass to the start of the next Colour: --ecg in style.css. Readers with "reduce motion" set do not see it at all. {% endcomment %}
